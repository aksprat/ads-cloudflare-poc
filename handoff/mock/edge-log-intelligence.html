ValidatedNamed agents separate cleanly by user agent: Cursor, Codex, Claude-User, Claude Code, opencode. Unlabeled agents exist: python-httpx2, undici, Bun and node are 14.9% of MCP requests, and 15 of 16 python-httpx2 IPs return across hourly slices.
ChangedJA3 alone cannot label agents. Cursor, Claude Code, Claude-User and opencode share TLS fingerprints with generic Node and Bun clients (93% of generic node requests match a named agent's JA3).
